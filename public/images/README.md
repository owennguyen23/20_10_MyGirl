# Ảnh quà tặng

Chỉ **2 món quà giá trị nhất** được hiển thị. Bỏ ảnh vào chính thư mục này (`public/images/`) với đúng tên file:

| File         | Món quà                    |
| ------------ | -------------------------- |
| `imac.png`   | iMac 24" xanh lá           |
| `iphone.png` | iPhone 18 Pro Max xanh lá  |

Các túi còn lại **không hiển thị nội dung** nên không cần ảnh.

Gợi ý:

- Định dạng **PNG nền trong suốt** để hoà vào thẻ quà.
- Kích thước ~**512–800px** cạnh dài, dung lượng < 300KB cho mỗi ảnh.
- Tỉ lệ đẹp nhất là **1:1** hoặc **4:3**.

Nếu chưa có ảnh, web vẫn chạy và hiện khung chữ với tên món quà — không bị lỗi.

Muốn đổi tên file khác thì sửa đường dẫn trong `src/config/game.ts`.
